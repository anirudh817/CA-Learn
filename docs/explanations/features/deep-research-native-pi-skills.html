Durable Deep Research now uses genuine native Pi skills

ResearchService remains the durable control plane. A filtered Pi AgentSession is now the execution plane for approved real SKILL.md packages, controlled scripts, native tools, artifacts, and receipts.

Former false-skill architecture → unified architecture

Before

A plan named exploratory-data-analysis dispatched unrelated ResearchSkillRunner.runEda() TypeScript and cited synthetic revision reviewed-adapter-v1.

After

An approved plan freezes reasoningProfiles and allowedSkills. Pi receives only those real packages, reads the real SKILL.md, chooses activation, and may call an approved script or native tool. “Allowed but unused” is recorded honestly.

ResearchService → approved profiles + skill allowlist → one controlled Pi AgentSession → filtered skillsOverride → read_skill → sf_skill_run/native tool → receipt → artifacts → synthesis

Control plane versus execution plane

ResearchService: job creation, plan approval, frozen scope, source/budget policy, queue/pause/resume/stop/retry, SSE events, evidence, deliverables, and OCC views.

Pi: DefaultResourceLoader, filtered skillsOverride, createAgentSession(), SessionManager, activation decisions, model turns, and custom tools. Durable research exposes no generic Bash, Python, write, or edit. Standard remains zero-tool and zero-skill.

Profiles and routing

Reasoning profiles are guidance, not executable skills. Finding stability uses biostatistician and data-scientist; pathway investigation uses bioinformatician and systems-biologist. Unapproved packages are absent, not merely discouraged.

Gateway, isolation, environments, network

  • Per-job workspace; frozen inputs are hash-verified, copied read-only, and separated from writable outputs.
  • Exact skill/script allowlists reject unknown IDs, absolute paths, traversal, and arbitrary scripts.
  • Timeout, exit status, duration, bounded stdout/stderr, and output hashes are captured.
  • Heavy environments use isolated cached uv specs: pyOpenMS 3.5.0, PyDESeq2 0.5.4, Scanpy 1.12.x.
  • Direct network skills remain disabled. Proxy variables are defense in depth, not claimed as an OS sandbox.
  • Secondary-LLM helpers cannot bypass SignalFold model and budget controls.

Receipts and truthful determinism

Receipts include job/step/Pi session, profiles, approved/activated skills, SKILL.md and folder hashes, upstream revision, executable and arguments, environment, input/output hashes, timing/status, streams, determinism, and network activity.

Automatic deterministicRerun: "exact" was removed. Records start not-checked; only a real matching deterministic child rerun becomes exact-rerun-verified. Historical adapter records surface as legacy-pre-native-pi.

Native Stage 1 stability

skills/native/stage1-finding-stability/SKILL.md is genuine. When approved and activated, Pi calls stage1_finding_stability, which verifies the frozen DE artifact/hash, reuses the deterministic threshold sweep, and emits a hashed CSV. No replacement scientific Python was created.
